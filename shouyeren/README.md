# 灯火守夜人

一款无需安装、打开即玩的 Canvas 街机小游戏。移动灯笼收集萤火，避开雨滴，在天亮前尽可能点亮更多街灯。

现在包含玩法首页、本地灯火排行榜和带倒计时光环的限时萤火。每局结束后会在当前浏览器记录游玩时间、灯光分数与最高连击。

## 开始游戏

直接打开 `index.html`，或使用任意静态文件服务器：

```bash
npx serve .
```

## 操作

- 键盘：方向键或 `WASD`
- 鼠标/触屏：在游戏区域拖动
- `P` 或空格：暂停/继续

游戏进度和最高分会自动保存在浏览器中。

## GitHub Pages

在仓库的 **Settings > Pages** 中，将 **Source** 设为 `Deploy from a branch`，选择 `main` 分支和根目录即可发布。

## 技术

原生 HTML、CSS 和 JavaScript，无第三方依赖。
